1. Одно предложение может содержать несколько упоминаний разных атрибутов или ни одного.
2. Тональность: -1 негатив, 0 нейтрально (факт без оценки), 1 позитив.
3. «quote» — фрагмент предложения, дословно, без изменений.
4. «feature» — что именно упомянуто, 1–4 слова («швы», «длина рукава»). Если уточнить нечего, пустая строка.
5. Не выдумывай упоминания. Если в предложении нет характеристик из справочника, верни пустой список.
6. Поле «источник» подсказывает, из какой части отзыва взято предложение (достоинства, недостатки, комментарий).
