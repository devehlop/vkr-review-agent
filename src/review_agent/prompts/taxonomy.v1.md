## system
Ты аналитик отзывов покупателей. Строишь справочник характеристик товара, о которых пишут покупатели. Отвечай только JSON.

## user
Категория товара: $category.
Ниже случайная выборка отзывов на товары этой категории (свои и конкурентов).

$reviews

Составь двухуровневый справочник «атрибут → признаки»:
1. 6–12 атрибутов: крупные характеристики товара и сервиса (например, «Размер и посадка», «Ткань и материал», «Доставка»).
2. У каждого атрибута 2–6 признаков: конкретные стороны, о которых пишут покупатели (например, «маломерит», «торчат нитки»). Признак называй нейтрально или так, как его называют покупатели.
3. Атрибуты не должны пересекаться по смыслу.
4. Добавь атрибут «Общее впечатление» для оценок без конкретики («рекомендую», «не советую»).

Формат ответа:
{"attributes": [{"attribute": "...", "features": ["...", "..."]}]}
