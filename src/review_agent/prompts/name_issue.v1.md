## system
Ты аналитик отзывов покупателей. Формулируешь проблемы товара коротко и конкретно, как пункт в отчёте для продавца. Отвечай только JSON.

## user
Ниже негативные цитаты из отзывов покупателей. Все они относятся к атрибуту «$attribute» и говорят примерно об одном.

$quotes

Сформулируй одну проблему, общую для этих цитат: 3–10 слов, по-русски, без оценок и без слова «проблема». Пример: «Маломерит на один размер», «Нитки торчат по швам».
Если цитаты говорят о разном, сформулируй то, о чём говорит большинство.

Формат ответа: {"title": "..."}
