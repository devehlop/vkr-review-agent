# Данные

## Источник

**RuReviews** — отзывы на товары категории «Женская одежда и аксессуары» с крупной площадки,
90 000 отзывов, по 30 000 на класс (negative / neutral / positive), тональность получена из
оценки покупателя автоматически.

- Репозиторий: https://github.com/sismetanin/rureviews (коммит `2f6e61d`, файл `women-clothing-accessories.3-class.balanced.csv`)
- Лицензия: Apache 2.0
- Ссылка для списка литературы: Smetanin S., Komarov M. Sentiment Analysis of Product Reviews in Russian using Convolutional Neural Networks // 2019 IEEE 21st Conference on Business Informatics (CBI). 2019. Vol. 01. P. 482–486. DOI: 10.1109/CBI.2019.00062

## Персональные данные

В исходном датасете есть отзывы с телефонами, почтой, ссылками и номерами заказов
(168 из 90 000 по автоматической проверке). Поэтому:

- исходный файл в репозиторий **не кладётся**, он скачивается скриптом в `data/raw/` (папка в `.gitignore`);
- при подготовке выборок такие отзывы выбрасываются целиком (`src/review_agent/preprocess/pii.py`);
- выборки в `data/annotation/` дополнительно просмотрены по ключевым словам (город, улица, имя, ник, соцсети): контактов и имён нет. Остались упоминания регионов доставки и параметров фигуры без привязки к человеку.

## Как получить

```bash
python scripts/prepare_rureviews.py
```

Скрипт скачивает файл, проверяет контрольную сумму, чистит данные и пересоздаёт выборки.
Выборки детерминированы (seed 2026): при повторном запуске получаются те же предложения.

Итог последнего запуска: всего 90 000, с персональными данными 168, пустые и дубли 5 068, осталось 84 764.

## Выборки для разметки (`data/annotation/`)

| Файл | Размер | Назначение |
|---|---|---|
| `fewshot` | 30 предложений | Примеры для промпта (few-shot). Не участвуют в оценке |
| `mini` | 100 предложений | Мини-эксперимент по выбору LLM (`docs/architecture.md`, раздел 4) |
| `test` | 300 предложений | Итоговая оценка качества (`docs/tz.md`, раздел 6) |

Выборки не пересекаются, из каждого отзыва взято одно предложение (3–40 слов),
классы тональности отзыва представлены поровну. Каждый файл есть в CSV и XLSX: размечать
удобнее в XLSX (выпадающие списки), в CSV хранится то же самое.

Как размечать: `eval/annotation_guide.md`.

## Демонстрационный набор (`data/samples/`)

`demo_own.csv` (180 отзывов) и `demo_competitor.csv` (148) делает скрипт `scripts/make_demo_data.py`.
**Тексты отзывов реальные** (очищенный RuReviews, без отзывов из выборок для разметки), а
**разбивка по товарам, оценки и даты сгенерированы**: в RuReviews нет привязки к товару. У «своего»
товара больше жалоб на размер, у «конкурента» — на ткань, чтобы было видно сравнение. Набор
только для демонстрации и отладки, выводы по нему ничего не говорят о реальных товарах.
