## 19.11.2026 — что можно сделать без ключей

**Проверено:** в облачной среде настроен доступ к GigaChat, но оба пробных запроса вернули `502 upstream request failed`. Вероятно, указан не тот адрес получения токена (обычно `ngw.devices.sberbank.ru:9443`) или прокси не доверяет сертификату НУЦ Минцифры.

**Сделано (отчёт решили не делать в этой сессии):**
- Данные: RuReviews скачивается скриптом `scripts/prepare_rureviews.py`. 168 отзывов с персональными данными (телефоны, почта, ссылки, номера заказов) выбрасываются, сам датасет в репозиторий не кладётся. Выборки для разметки: `fewshot` (30), `mini` (100), `test` (300) в CSV и XLSX с выпадающими списками.
- Черновой справочник аспектов для одежды (11 атрибутов) и инструкция по разметке `eval/annotation_guide.md`. Разметка на уровне атрибут + тональность, признаки по желанию.
- Код: каркас проекта, загрузка CSV/XLSX, предобработка и маскирование ПД, LLM-шлюз (схема, повторы с текстом ошибки, кэш, журнал, стоимость), клиенты GigaChat, YandexGPT, Ollama и заглушка, шаги 4, 5, 10, 11, SQLite, метрики (F1, macro-F1, каппа), словарный метод как нижняя граница, скрипт мини-эксперимента. 45 тестов, автоматический запуск на GitHub.
- Найдена и исправлена ошибка: отметка «ответ не по формату» не доходила до журнала в SQLite.

**Решения, которые принял Claude и которые надо подтвердить:**
- Эталонная разметка без признаков: справочник признаков модель строит сама, сравнивать признаки напрямую нельзя.
- Если атрибут в предложении упомянут и позитивно, и негативно, при сравнении с эталоном это считается нейтральным (0).
- Для GigaChat temperature не ниже 0,01: по документации ноль недопустим, проверить на реальном API.
